# Projeto
Portfólio Pessoal

## Status
Projeto finalizado.

## Descrição
Projeto de um portfólio pessoal composto por uma página principal e uma página "Sobre Mim". O objetivo é apresentar o desenvolvedor e disponibilizar links diretos para suas redes sociais, como Instagram, GitHub e LinkedIn.

## Observação
A estrutura e a estilização do projeto foram construídas do zero, com destaque para as seguintes implementações:
* Utilização de variáveis CSS para a padronização e fácil manutenção das cores e fontes do projeto.
* Importação das famílias de fontes "Krona One" e "Montserrat" através do Google Fonts.
* Aplicação do Flexbox para estruturação, alinhamento e distribuição de espaço no layout.
* Implementação de media query (para larguras de até 1200px) garantindo a responsividade das páginas.

## Tecnologias
- HTML
- CSS
